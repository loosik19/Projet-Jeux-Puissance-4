# Projet-Jeux-Puissance-4
Ce projet consiste en une implémentation du célèbre jeu Puissance 4 en langage C, jouable directement dans la console. Le jeu oppose deux joueurs qui jouent chacun leur tour en plaçant un pion dans une grille verticale. Le premier joueur à aligner 4 pions horizontalement, verticalement ou en diagonale remporte la partie.
